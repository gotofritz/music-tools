How to add a sound file

  1. Find the file on your computer — an audio file (.wav, .mp3, .flac, .m4a…) or a video (.mp4, .mov…; only its sound is used).
  2. Copy its absolute path, the one that starts with /. On a Mac, select the file in Finder and press ⌥⌘C; on Linux, most file managers have “Copy path”, or run realpath file.wav in a terminal.
  3. Paste it into the first box below and press attach audio or video. The file stays where it is — it is never copied, and the path must be inside the folders listed below.
  4. Go back to {{ module.name }} and press start on this row. Today's page then shows a player for the file: a waveform (click it to jump), play, loop, a speed slider that sets this row's speed, and a pitch control in semitones.

Several files can be one tune — stems, or a backing track beside a click: attach the first, then add the others to its set from the card above (up to eight, all the same length). For now a set plays as separate players; one shared transport is still to come.
